المهارات في مرحلة التطوير وإجراءات الاعتماد ولم ننشرها للعامة بعد. تصف هذه الصفحات طريقة عملها الحالية على استضافة أمازون.

These skills are in development and certification preparation and have not been published for public use. These pages describe their current Amazon-hosted implementation.

ما نحفظه

تحفظ عزيمتي عدد الضيوف الاختياري الذي تدخله (١–١٠٠)، والمهام المختارة من ست فئات ثابتة: الجلسة، والأكواب، والقهوة، والتمر، والتقديم، والتنظيف؛ وحالة إنجاز كل مهمة، ونسخة واحدة من آخر تغيير للتراجع، ورقم إصدار متزايد. لا تحفظ أسماء ضيوف أو مهام مملاة بحرية، ولا تجمع جهات اتصال أو عناوين أو أرقام هاتف أو مدفوعات أو موقعاً دقيقاً أو تسجيلات صوتية خام.

What is stored

Azimti stores the optional guest count you enter (1–100), tasks selected from six fixed categories—seating, cups, coffee, dates, serving and cleaning—their completion status, one previous-change snapshot for undo, and a monotonically increasing version. It does not store guest names or freely dictated tasks, or collect contacts, addresses, telephone numbers, payments, precise location or raw audio recordings.

الحساب المشترك

تحفظ عزيمتي السجل باستخدام معرّف مستخدم المهارة المبهم الذي ترسله أمازون. أي شخص يمكنه استدعاء المهارة بذلك الحساب قد يسمع السجل ويغيره. لا تتعرف الخدمة على المتحدث ولا تستخدم تحققاً صوتياً. تبديل حساب Amazon Household أو ملف أليكسا قد يؤدي إلى سجل مختلف، ولا ينشئ مشاركة تلقائية.

Shared-account access

Azimti stores its checklist under Amazon’s opaque skill user identifier. Anyone able to invoke the skill under that account may hear or change its records. The service does not identify individual speakers or use Voice ID authentication. Amazon Household account/profile switching may yield different records; it does not automatically share a ledger.

موثوقية الطلبات والحذف

يحفظ السجل أيضاً سياق التأكيد والشاشة الحالي بين الطلبات، وآخر ثماني استجابات، وحتى ٣٢ معرّف طلب مبهم لمعالجة إعادة المحاولة والتزامن. اطلب حذف البيانات بالصوت ثم أكد بنعم. يحذف التأكيد محتوى المستخدم وسجل التراجع إن وجد والاستجابات السابقة وسياق الجلسة السابق. يبقى معرّف الحساب المبهم ومعلومات الإصدار ومعرّفات الطلبات الحديثة لمنع التغييرات القديمة وإعادة الطلبات؛ قد تبقى هذه البيانات التقنية محفوظة دون مدة حذف تلقائي محددة. قد تحفظ استجابة أو شاشة جديدة فارغة بعد الحذف. إذا تغيرت البيانات أثناء التأكيد يجب طلب الحذف مجدداً.

Request reliability and deletion

For retry and concurrency protection, the record also stores current confirmation/display context across requests, the last eight response envelopes and up to 32 opaque request IDs. Request deletion by voice and confirm yes. Confirmed reset removes user content, undo history where present, previous response caches and previous session context. The opaque account key, version information and recent request IDs remain to reject stale writes and replays; this technical metadata can remain stored without a fixed automatic deletion period. A new blank response/display may then be cached. A concurrent change invalidates an older deletion confirmation.

مدة الاحتفاظ والحماية

بعد ٩٠ يوماً دون استخدام، يتوقف التطبيق عن استرجاع محتوى المستخدم المحفوظ. هذه مدة صلاحية للاستخدام داخل التطبيق، وليست وعداً بحذف السجل المخزن في ذلك الموعد. الحذف التلقائي في الخلفية غير مفعّل في تخزين أمازون الحالي. قد يبقى المحتوى المنتهي مخزناً حتى حذف مؤكد أو طلب لاحق للمهارة يستبدل السجل المنتهي. وقد تبقى بيانات الحساب والإصدار ومعرّفات الطلبات التقنية بعد إعادة الضبط. التخزين مشفر على الخادم. يسجل كود التطبيق فئة خطأ عامة ثابتة فقط، دون طلبات كاملة أو معرّفات مستخدم أو رموز شاشة أو محتوى سجل. تحتفظ أمازون أيضاً بسجلات تشغيل الاستضافة وفق ضوابطها؛ لا نضمن مدة احتفاظ ثابتة بهذه السجلات تحت تحكم المشغل. حذف محتوى المهارة لا يعد بحذف سجلات تشغيل أمازون أو أي نسخ احتياطية أو تصديرات منفصلة.

Retention and security

After 90 days without use, the application stops restoring saved user content. This is an application inactivity limit, not a promise that the stored record is deleted at that time. Automatic background deletion is not enabled in the current Amazon-hosted storage. Expired user content can remain stored until a confirmed reset or a later skill request replaces the expired record. Account, version and request metadata can remain after reset. Storage is encrypted on the server. Application code logs only a fixed generic error class, not full requests, user IDs, display tokens or record content. Amazon also retains hosting operational logs under its own controls; no fixed retention period for those logs under the operator’s control is guaranteed. Clearing skill content does not promise to erase Amazon operational logs or any separate backups or exports.

أليكسا والخدمات الخارجية

تعالج أمازون الصوت وطلبات الجهاز بصورة منفصلة وفق سياساتها. لا تتلقى هذه المهارة تسجيل الميكروفون الخام. حذف سجل المهارة لا يحذف سجل صوت أمازون؛ استخدم أدوات خصوصية أليكسا لإدارته. يستخدم التنفيذ أليكسا وAWS، دون مشتريات أو إعلانات أو تحليلات أو تكاملات خارجية أو بيع للبيانات. لا تتضمن هذه الصفحات نماذج إدخال أو نصوصاً برمجية أو تحليلات أو أصولاً أو خطوطاً من شبكة خارجية.

Alexa and other services

Amazon separately processes voice and device requests under its own policies. This skill does not receive raw microphone recordings. Clearing skill records does not delete Amazon voice history; manage that through Alexa privacy controls. The implementation uses Alexa and AWS, with no purchases, ads, analytics, external integrations or sale of data. These pages contain no forms, scripts, analytics or externally hosted assets or fonts.

طلب الحذف والدعم

قل «احذف البيانات» ثم «نعم» لحذف المحتوى. إيقاف تفعيل المهارة ليس حدث حذف تلقائياً في هذا التنفيذ؛ اطلب الحذف المؤكد أولاً، أو تواصل مع Ahmed عبر alexa@ahmed-ibrahim.com. لا تنشر معرّف حسابك أو تفاصيل المنزل في قضايا عامة. راجع صفحة الدعم لمعرفة بيانات رسالة البريد.

Deletion and support

Say “clear my data,” then “yes” to delete content. Disabling the skill is not automatically treated as deletion by this implementation. Invoke confirmed reset first or contact Ahmed at alexa@ahmed-ibrahim.com. Do not post account identifiers or household details in public issue trackers. See support for information about email data.
