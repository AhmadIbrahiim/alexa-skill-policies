المهارات الثلاث غير منشورة حالياً. تصف هذه الصفحات التنفيذ الحالي وإعداد النشر المقدم، ولا تدّعي وجود خدمة منشورة أو مستخدمين فعليين.

All three skills are currently unpublished development prototypes. These pages describe the current implementation and supplied deployment configuration; they do not claim a live service or actual deployed users.

ما نحفظه

تحفظ الفزعة معرّفات المعدات وعلاقة المستعير للسجلات الحالية، ونسخة واحدة من سجل الإعارة السابق للتراجع مع معرّفات آخر تغيير، ورقم المخطط والإصدار. الكتالوج ثابت: الخيمة، والكراسي، والدلة، وحافظة التبريد، والشواية؛ والمستعير هو الوالد أو الأخ أو الصديق أو الجار. هذه تسميات علاقات وليست أسماء أشخاص حقيقية. لا تحفظ نصوصاً حرة، ولا تجمع جهات اتصال أو عناوين أو أرقام هاتف أو مدفوعات أو موقعاً دقيقاً أو تسجيلات صوتية خام.

What is stored

Al Faza stores equipment/borrower-relation IDs for current loans, one preceding loan snapshot for undo with the last-change IDs, and schema and version numbers. Its fixed catalog is tent, chairs, coffee pot, cooler and grill; borrowers are father, brother, friend or neighbor. These are neutral relations, not real personal names. It does not store free-form text or collect contacts, addresses, telephone numbers, payments, precise location or raw audio recordings.

الحساب المشترك

تحفظ الفزعة سجلاً منفصلاً لكل حساب باستخدام معرّف مستخدم المهارة المبهم الذي ترسله أمازون. أي شخص يمكنه استدعاء المهارة بذلك الحساب قد يسمع السجل ويغيره. لا تتعرف الخدمة على المتحدث ولا تستخدم تحققاً صوتياً. تبديل حساب Amazon Household أو ملف أليكسا قد يؤدي إلى سجل مختلف، ولا ينشئ مشاركة تلقائية.

Shared-account access

Al Faza uses Amazon’s opaque skill user identifier and stores separate account records. Anyone able to invoke the skill under that account may hear or change its records. The service does not identify individual speakers or use Voice ID authentication. Amazon Household account/profile switching may yield different records; it does not automatically share a ledger.

موثوقية الطلبات والحذف

يحفظ السجل أيضاً سياق التأكيد والشاشة الحالي لاستخدامه بين الطلبات، وآخر ثماني استجابات، وحتى ٣٢ معرّف طلب مبهم لمعالجة إعادة المحاولة والتزامن. احذف البيانات بالصوت ثم أكد بنعم. يحذف التأكيد محتوى المستخدم وسجل التراجع إن وجد وسجل الاستجابات السابق وسياق الجلسة السابق. يبقى رقم إصدار ومعرّفات طلبات حديثة حتى انتهاء صلاحية السجل بعد ٩٠ يوماً دون استخدام لمنع التغييرات القديمة وإعادة الطلبات. قد تحفظ استجابة أو شاشة جديدة فارغة بعد الحذف. إذا تغيرت البيانات أثناء التأكيد يجب طلب الحذف مجدداً.

Request reliability and deletion

For retry and concurrency protection, the record also stores current confirmation/display context across requests, the last eight response envelopes and up to 32 opaque request IDs. Request deletion by voice and confirm yes. Confirmed reset removes user content, undo history where present, previous response caches and previous session context. A version tombstone and recent opaque request IDs remain until record expiry after 90 days without use to reject stale writes and replays. A new blank response/display may then be cached. A concurrent change invalidates an older deletion confirmation.

مدة الاحتفاظ والحماية

تنتهي صلاحية السجل بعد ٩٠ يوماً دون استخدام. تتعامل قراءات التطبيق فوراً مع المحتوى المنتهي كغير متاح؛ الحذف الفعلي بواسطة DynamoDB TTL يحدث لاحقاً بصورة غير فورية. التخزين مشفر على الخادم. يقصر إعداد النشر المقدم صلاحيات قراءة دور وظيفة المهارة وكتابته على جدولها فقط. تسجل أخطاء التطبيق فئة خطأ عامة ثابتة فقط، دون طلبات كاملة أو معرّفات مستخدم أو رموز شاشة أو محتوى سجل. تحتفظ مجموعة CloudWatch المقدمة بالسجلات لمدة ١٤ يوماً. يبقى الجدول عند حذف حزمة النشر أو استبدالها؛ حذف الحزمة لا يحذف سجلات المستخدمين. على المشغل مراجعة الاحتفاظ والحذف بصورة منفصلة لأي نسخ احتياطية أو استعادة إلى نقطة زمنية أو تصديرات يفعّلها في AWS؛ لا تعد هذه السياسة بأن حذف بيانات المهارة يحذف تلك النسخ.

Retention and security

Records expire after 90 days without use. Application reads immediately treat expired content as unavailable; DynamoDB TTL physically removes it asynchronously afterward. Server-side storage encryption is enabled. The supplied deployment limits the skill function role to its own table. Application errors log only a fixed generic error class, not full requests, user IDs, display tokens or record content. The supplied CloudWatch log group retains logs for 14 days. The table is retained when the deployment stack is deleted or replaced; stack deletion does not erase user records. The operator must review retention and deletion separately for any AWS backups, point-in-time recovery or exports they enable; this policy does not promise that resetting skill data deletes those copies.

أليكسا والخدمات الخارجية

تعالج أمازون الصوت وطلبات الجهاز بصورة منفصلة وفق سياساتها. لا تتلقى هذه المهارة تسجيل الميكروفون الخام. حذف سجل المهارة لا يحذف سجل صوت أمازون؛ استخدم أدوات خصوصية أليكسا لإدارته. يستخدم التنفيذ أليكسا وAWS، دون مشتريات أو إعلانات أو تحليلات أو تكاملات خارجية أو بيع للبيانات. لا تتضمن هذه الصفحات نماذج إدخال أو نصوصاً برمجية أو تحليلات أو أصولاً أو خطوطاً من شبكة خارجية.

Alexa and other services

Amazon separately processes voice and device requests under its own policies. This skill does not receive raw microphone recordings. Clearing skill records does not delete Amazon voice history; manage that through Alexa privacy controls. The implementation uses Alexa and AWS, with no purchases, ads, analytics, external integrations or sale of data. These pages contain no forms, scripts, analytics or externally hosted assets or fonts.

طلب الحذف والدعم

قل «احذف بياناتي» ثم «نعم» لحذف المحتوى. إيقاف تفعيل المهارة ليس حدث حذف تلقائياً في هذا التنفيذ؛ اطلب الحذف المؤكد أولاً، أو انتظر انتهاء صلاحية عدم الاستخدام، أو تواصل مع Ahmed عبر alexa@ahmed-ibrahim.com. لا تنشر معرّف حسابك أو تفاصيل المنزل في قضايا عامة. راجع صفحة الدعم لمعرفة بيانات رسالة البريد.

Deletion and support

Say “delete my data,” then “yes” to delete content. Disabling the skill is not automatically treated as deletion by this implementation. Invoke confirmed reset first, allow inactivity expiry or contact Ahmed at alexa@ahmed-ibrahim.com. Do not post account identifiers or household details in public issue trackers. See support for information about email data.
